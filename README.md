# 📁 檔案整理轉檔

把一大堆照片、文件丟進網頁，自動分好資料夾；也能用圖形介面簡單轉檔。

**🔒 隱私優先：所有處理都在你的瀏覽器裡完成，檔案不會上傳。** 網頁設定了安全規則，禁止連到任何外部網址，斷網也能用。

## 功能

### 🏠 入口首頁
打開網站先看到首頁：小助手打招呼，兩個大按鈕「自動整理」、「轉檔」直接打開工具；也可以把檔案拖到首頁（或按「選擇檔案」），會自動進入自動整理。
網址可以直接指定工具：`index.html#organize`、`index.html#convert`，瀏覽器的上一頁也能返回。

### 🗂️ 自動整理
分類順序：**名字 → 類型 → 日期**（每一層都可以關掉）

| 層級 | 說明 |
|---|---|
| 名字 | 你輸入名字（例如：王小明、Amy），檔名或原資料夾名稱有這個名字的檔案，就放進同一個資料夾。網站也會從檔名中找出常出現的詞，點一下就能加入。 |
| 類型 | 照片、影片、音訊、文件、試算表、簡報、壓縮檔、其他 |
| 日期 | 照片優先用**拍攝日期**（EXIF），其次是**檔名裡的日期**（如 `IMG_20250812`），最後用檔案修改日期。可選：年／年-月／年/月兩層／年-月-日 |

範例結果：
```
王小明/照片/2025-08/王小明_旅行.jpg
王小明/文件/2026-11/合約_王小明.pdf
照片/2022-12/IMG_0001.jpg
試算表/2026-11/成績.xlsx
```

- 處理前可以先**預覽**資料夾結構，也能手動改任何檔案要放的資料夾
- 同名檔案自動改名成 `檔名 (2).jpg`，不會覆蓋
- 可選擇把 iPhone 的 HEIC 照片順便轉成 JPG
- 輸出：**下載 ZIP**（所有瀏覽器），或**直接存到電腦資料夾**（Chrome / Edge）

### 🔄 轉檔
| 功能 | 支援 |
|---|---|
| 圖片轉格式／壓縮 | JPG、PNG、WebP、HEIC、GIF、BMP、AVIF → JPG / PNG / WebP，可調畫質與最大尺寸 |
| 圖片合併成 PDF | A4（自動直／橫）或與圖片同大小，可調整頁序 |
| 表格轉換 | XLSX、CSV、TSV、JSON 互轉；自動辨識 Big5 編碼的舊 CSV；輸出的 CSV 用 Excel 開中文不亂碼 |

轉出來的圖片會自動移除 GPS 位置等 EXIF 資訊。

### 🤖 檔案整理小助手
右下角的小機器人，**點一下才會出現**圖解教學：每一步都有小動畫，並會把畫面上對應的區塊框起來。切換到「轉檔」分頁時會換成轉檔教學。按 Esc 或 ✕ 關閉。

### 🔒 隱私政策
網站內有完整的隱私政策頁（`index.html#privacy`，從頁首、首頁和頁尾都能點進去），說明讀取哪些資訊、不收集什麼、照片 EXIF/GPS 的處理方式，以及如何自己確認檔案沒有上傳。

## 使用方式

- **直接開啟**：下載整個專案，雙擊 `index.html` 即可（不需安裝、不需網路）。
- **放上網路**：這是純靜態網站，可以免費放在 GitHub Pages：
  repo 的 Settings → Pages → Source 選 `Deploy from a branch`，選分支與 `/ (root)`。

## 限制

- 檔案都在瀏覽器記憶體裡處理，一次處理幾 GB 以上可能變慢或失敗，建議分批，或改用「直接存到電腦資料夾」。
- 名字分類是比對文字，不會辨識照片裡的人臉。
- 影片轉檔、Word / PPT 轉 PDF 尚未支援。
- 從 XLSX 讀出的日期欄位會是 Excel 的日期序號數字。

## 專案結構

```
index.html          頁面
css/style.css       樣式（可愛圓角風格，支援深色模式、手機版）

js/converter.js     圖片、HEIC、PDF 轉檔
js/table.js         CSV / XLSX / JSON 讀寫
js/app.js           介面
js/guide.js         小幫手機器人教學
vendor/             JSZip（ZIP 讀寫）、heic2any（HEIC 解碼），皆為 MIT 授權
```
